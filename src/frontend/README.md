# LatentSeas Frontend

Interactive 3D visualization of GPT-2's feature landscape using Three.js.

## Features

- 3D terrain rendering with interpolated heights
- Interactive feature markers (clickable)
- Real-time probe visualization (highlights activated features in red)
- Flag placement (green markers)
- Text generation based on placed flags

## Color Coding

- **Gray spheres** - Inactive features
- **Red spheres (larger)** - Activated features from probe
- **Green spheres (largest)** - Placed flags

## Controls

- **Mouse drag** - Rotate the view
- **Scroll wheel** - Zoom in/out
- **Click on sphere** - Place or remove flag
